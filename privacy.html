Privacy Policy

Procam YouTube Dashboard · Last updated 28 October 2026

What this app is

The Procam YouTube Dashboard is an internal reporting tool for Procam International. It shows statistics for Procam International's own YouTube channel: subscriber count, views, video performance, watch time, traffic sources and aggregated audience demographics.

What data it accesses

With the channel owner's permission, the app uses the YouTube Data API and YouTube Analytics API with read-only access (youtube.readonly and yt-analytics.readonly). It can only read data; it cannot upload, edit or delete anything on YouTube.

The only data collected is channel-level and video-level statistics, plus audience data that YouTube provides in aggregated, anonymous form (for example, percentage of viewers by age group or country). The app does not collect information about individual viewers, and it does not use cookies or tracking on this website.

How the data is used and stored

The statistics are saved as data files in the dashboard's GitHub repository and displayed on this website. They are not sold, shared with advertisers, or used for any purpose other than reporting on the channel's performance. The OAuth credentials are stored as encrypted GitHub Actions secrets and are never published.

Revoking access

The channel owner can revoke this app's access at any time from Google Account → Security → Third-party apps. Once access is revoked, the dashboard stops updating.

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
